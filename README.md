# Umer Mehboob Khan — Portfolio

Next.js + Tailwind CSS + Framer Motion portfolio.

## Run
```
npm install
npm run dev
```

## Where to edit
- `lib/data.js` — name, links, CV link, skills, experience, education, projects
- `public/profile.png` — replace with your own photo (square, 800x800 works well)
- `public/projects/` — replace the cover images with real screenshots (keep the file names or update `image` in `lib/data.js`)
- `lib/data.js` → `site.url` — set to your real domain after deploying
